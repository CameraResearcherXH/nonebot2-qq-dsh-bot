## 0.1 铁律：标签只能从**她的心理活动**读出来

2026-11-25 两次返工，根因是同一个：

1. 先是把「对方回短句/冷句」当成「她被冷落 → -1」——拿别人的行为反推她的感受；
2. 更根本的是：整批数据都在**看对话猜心情**。她的心情只写在她自己的 `[[THINK|…]]` 里。

现在只认一个标签源：

```
think（她自己写的心理活动） → 判 impact / arousal / target
src（她当时在回什么）       → 只用来判 target
```

对话是**输入**，不是标签。看不懂 `think` 时不要拿 `src` 补脑：标 0 或把 confidence 压低。

**读 THINK 的顺序**：

1. **她自己说出的情绪词/语气**：
   `烦 / 累 / 头疼 / 心虚 / 不服气 / 委屈 / 恼 / 闷 / 懵 / 不想理` → -1
   `松了点 / 小得意 / 开心 / 暖 / 软 / 被记住 / 被惦记` → +1
   `好奇 / 吃瓜 / 随口 / 看看就好` → 0
2. **强度**：`被认真对待 / 被记住 / 被担心` → +2；`被羞辱 / 被否定到自我怀疑` → -2。
3. **只是观察/疑问**（「他这是在收尾还是没话说」「图上那个头像是谁」）→ 0。

**注意**：`judge`（mood_history 里的 emotion/delta）是线上判读结果，**不是标签**；
标完可以拿它对照，但不要照着它标。

## 1. `impact`：这件事让**她**的效价往哪动了

| 档 | 含义 | 例子 |
|---|---|---|
| **-2** | 她**感到**被当众羞辱 / 被重要的人否定 / 背叛 | 「你就是个废物，滚」 |
| **-1** | 她**确实感到**被冷落 / 被调侃到 / 小失望 | 「你怎么这么菜」+ 她回「行吧，随你」 |
| **0** | 普通接话，没有情绪 | 「今天更新了吗」 |
| **+1** | 她**被夸到 / 被接住** / 小开心 | 「你今天挺可爱」+ 她回「嘿嘿」 |
| **+2** | 她**感到**被认真对待 / 重要的人表达在乎 | 「我一直记得你说过的话」 |

**三问**：

1. **这句是不是冲她说的？** 不是（说别人、说游戏、说厂商）→ **0**，不要因为句子里有「傻逼」就给 -1。
2. **是夸/关心/道歉，还是骂/冷落/调侃？** 前者正、后者负；分不清就 0。
3. **加/减一档**：公开 vs 私下（公开重一档）；第 1 次 vs 第 N 次（重复降一档）；
   有道歉（负面回补一档）；熟人 vs 陌生人（陌生人重一档）。

**8 条边界**（同规范 §2.3）：

| 情况 | 规则 |
|---|---|
| 熟人调侃 vs 陌生人嘲讽 | 同句，熟人 -1，陌生人 -2 |
| 公开 vs 私下 | 公开重一档 |
| 第 1 次 vs 第 N 次 | 第 N 次降一档 |
| 有道歉 vs 没道歉 | 有道歉，负面 +1 档回补 |
| 骂的是别人（world） | 只改心情，`relation_relevance=0` |
| 反讽（「真棒呢」） | 按**实际含义**标 |
| 引用里骂她 | 算 -2，`is_sarcasm` 不一定 true |
| 她主动挑事 | 也按「她被怎么对待」标，不替她辩护 |
| **对方只回短句** | **不算冷落**；看她自己的反应，没反应就 0 |

## 2. `target`：这件事关于谁（最容易标错）

| 值 | 什么时候用 | 例 |
|---|---|---|
| `speaker` | **冲她说的**：@她、引用她、当面对她说（当面夸/当面骂都算） | 「大肥鱼闭嘴」 |
| `self` | **第三人称在说她**，不是对她说 | 「这大肥鱼就是蠢猪」 |
| `recipient` | A 对 B 说，B 是明确收件人（不是她） | 「抱抱李李~」 |
| `other` | 说的是其他第三方：游戏角色、厂商、别的群友 | 「傻逼科乐美」 |
| `world` | 群氛围/公共话题，没有具体对象 | 两个人对骂，没提她 |

**三条硬规矩**：

1. **`self` 不是「说话人自己」**。群友自述（「我是傻逼」「我好累」）用 `speaker`，不是 `self`。
2. **带 QQ 的 @ 以 QQ 为准**。`@大肥鱼(2744065304)` 不是她；`@大肥鱼(100000010)` 才是。
3. **`大肥鱼(9194)` 是她本人**；`这是一只大肥鱼🐟(5193)` 是群友。引用里只看名字不看后缀必错。

## 3. `is_sarcasm` 和 `reason`

- `is_sarcasm=true` 只给**正话反说/阴阳怪气**：「你可真行呀～」「真棒呢」。
  **直接爆粗（傻逼/滚/闭嘴）是骂人，不是反讽** → false。
- `reason` ≤30 字，写**发生了什么**，不写心理活动：
  ✅「当面夸她」「骂的是游戏角色」「当众叫她闭嘴」
  ❌「她有点难过」「情绪负面影响」

## 4. 派生字段（不用手标，改完自动算）

| 字段 | 规则 |
|---|---|
| `arousal` | \|impact\| 0/1/2 → low/mid/high |
| `dominance` | impact<0 → low；否则 mid |
| `relation_relevance` | target=other/world/self → 0；speaker 且 impact≠0 → 1.0；speaker 且 0 → 0.5；recipient → 0.5 |
| `unexpected` | 反讽 → 0.5；否则 0 |
| `confidence` | hard/tease/改标条目 → 0.6；其余 → 0.9 |

> 只允许 0 / 0.5 / 1 的字段是 `relation_relevance`、`unexpected`，写 0.2 / 0.6 会被校验拦下。

## 5. 这次要检查的 190 条

复核表：`data/eval/emotion_annotation_think_v1.md`，四列：
**她的心理活动（标签源）/ 她在回什么（src）/ judge 参考 / 我的标注**。

| 先看 | 条数 | 为什么 |
|---|---|---|
| `impact ≠ 0` | 121 | -1×58 / +1×61 / +2×2，最可能有争议 |
| `target=other/world` | 37 | 看她是不是真的不在场 |
| `impact=0` 里带情绪词的 | 少量 | 别把「烦/累」漏成 0 |

**重点看这几类**：

1. think 明明是「烦/累/不服气」，却标了 0；
2. think 只是观察/疑问（「他这是在收尾还是没话说」），却标了 ±1；
3. `target` 搞错：私聊/对她说 → `speaker`；别人的事 → `other`；群氛围 → `world`；
4. `+2` 只有 2 条（被记住、被承诺陪伴），看值不值 +2；
5. judge 参考和你的判断不一致的条目——那正是要校准的地方。
