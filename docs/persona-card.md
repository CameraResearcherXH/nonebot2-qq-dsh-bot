# 人格卡：格式、字段、参考来源

> 人格卡决定「她是谁」。本项目的实现参考了 **SillyTavern（AI 酒馆）character card v2**
> 的字段划分，以及 **MaiBot** 的「人设 + 记忆 + 关系」分层思路，但代码和格式都是独立实现。

---

## 1. 放在哪、怎么切换

```
services/Personality/
├── 你的角色名.txt
└── ...
```

- `.env` 里 `DEFAULT_PERSONA=<你的角色名>` 设默认人格；
- 聊天里：
  - `/persona list` 看全部可用人格
  - `/persona <名字>` 切换当前会话的人格
- 发行仓只带 `personality.example.txt`（通用模板），**不包含任何私人人格卡**。

---

## 2. 纯文本分段格式（本项目）

一个 `.txt` 文件就是一段 system prompt。建议按下面六节写，顺序不重要，但分节能让模型
更容易抓住重点：

| 节 | 作用 | 对应酒馆字段 |
|---|---|---|
| 一、你是谁 | 身份、来历、自我认知、别人怎么称呼你 | `description` |
| 二、性格与说话方式 | 表层/内里、句子长短、口头禅、标点、不会做的事 | `personality` |
| 三、场景与关系 | 在群里/私聊/对主人/对陌生人分别什么状态 | `scenario` |
| 四、语气样例 | 2~3 组「用户：… / 角色：…」 | `mes_example` |
| 五、最高原则 | 硬规则：先像真人、不复述设定、不写旁白… | `system_prompt` |
| 六、禁止 | 政治/色情/违法、AI 自曝、客服腔… | `post_history_instructions` 的一部分 |

完整模板见根目录 `personality.example.txt`。

> 2026-11-24：默认卡 `小鲸鱼proplus.txt` 只保留 **一、你是谁（含外貌）** 和 **二、性格**。
> 长度/分条/表情/记忆/心里话/心情/人称/工具目录/底线 都由固定区协议
> （`services/llm.py` 的 `_behaviour_protocol`）提供，不再写进人设卡；
> 说话案例也去掉，靠实际对话和表达学习自己长。

### 写法建议

1. **先像真人，再谈人设**：不要一上来就「你是一个 AI 助手」。
2. **用行为描述，不用形容词堆砌**：写「被夸会嘴硬两句，但尾巴会翘」比写「傲娇」有效。
3. **给具体例句**：模型会模仿 `mes_example` 的句长和标点。
4. **明确禁止项**：不复述设定、不输出 Markdown、不写括号动作、不自称语言模型。
5. **不要写隐私**：人格卡会进 prompt，也会进日志；不要放真实姓名、电话、地址。

## 3. 与 SillyTavern character card v2 的字段对照

酒馆的 PNG/JSON 角色卡常见字段，与本项目的映射：

| 酒馆字段 | 含义 | 本项目落点 |
|---|---|---|
| `name` | 角色名 | 文件名 / `DEFAULT_PERSONA` |
| `description` | 角色简介 | 「一、你是谁」 |
| `personality` | 性格摘要 | 「二、性格与说话方式」 |
| `scenario` | 当前场景 | 「三、场景与关系」 |
| `first_mes` | 开场白 | 不直接使用；可写进「四、语气样例」 |
| `mes_example` | 对话样例 | 「四、语气样例」 |
| `system_prompt` | 系统提示 | 「五、最高原则」 |
| `post_history_instructions` | 历史后的追加指令 | 「六、禁止」 |
| `alternate_greetings` | 备选开场 | 可选，写进语气样例 |
| `character_book` | 角色世界书 | 用 `services/lorebook.py` 的词条系统 |

> 本项目的档案系统（`services/profiles.py`）是**按人**的，不是角色卡的一部分：
> 角色卡描述「她是谁」，档案描述「她怎么看你」。两者分开，避免人设和关系互相污染。

## 4. 与 MaiBot / maimai 的关系

- **MaiBot**：参考它「人设 + 长期记忆 + 关系状态」分层的思路；
  本项目用 `Personality/*.txt`（人设）+ `memory_v2`（记忆）+ `profiles`（关系）分开实现。
- **maimai**：参考「用户对话学习」——聊天里的经历沉淀成可检索记忆，再反过来影响对话；
  本项目落在 `services/memory_v2.py` / `memdb.py`。
- 两者都只是**思路参考**，没有复制代码。详见 [CREDITS.md](CREDITS.md)。

## 5. 最小可用人格卡

如果不想写太长，至少写清这四件事：

```
你是<名字>，<一句话身份>。
你说话<长短/语气/口头禅>。
别人<称呼>你时，你会<反应>。
你不做：<最不能接受的行为>。
```

然后跑一次 `/persona list` 确认能加载，再聊两句看语气对不对。
