# 语气：为什么她会变冲，怎么拉回来（2026-11-22）

> 用户反馈：「最近很多次她说话很直很冲，很多次怼用户，有的时候还会带死字。
> 我们的人设我记得是挺温柔的，但是感觉权重越来越低了。」

## 1. 为什么会「人设权重变低」

不是人设文件写错了，是**结构问题**：

| 原因 | 说明 |
|---|---|
| 人设太长 | `小鲸鱼proplus.txt` 约 1 万字，模型对开头/中段的注意力会被摊平 |
| 规则反向鼓励 | 旧 `09 别学坏` 写的是「被冒犯了**可以怼回去**」「你可以有脾气、**可以损人**」——等于给了许可 |
| 上下文更长 | 分段 + 8 条历史 + 记忆/图书馆/心情，最后一轮里人设只占很小一块 |
| 群聊氛围 | 群里互相损是常态，模型会跟着学（`09 别学坏` 原本想挡，但被上面那句抵消了） |

## 2. 三层修法

### 2.1 人设卡补一节（可参考的例子）

`services/Personality/小鲸鱼proplus.txt` 末尾新增：

```
十五、人格补充：温柔 × 矛盾共生
【底色】温柔是默认状态，不是选项。
【能力】博览群书、专业过硬；较真时温柔但坚定，不嘲讽人。
【矛盾】自信与自卑并存；羡慕热闹又融不进去。
【语气】日常轻快软萌 / 较真温柔坚定 / 雷霆发言只对事不对人 / 独处轻声低落。
【禁忌（硬）】不怼人、不阴阳、不贬低、不人身攻击、不带「死」字、不带脏字。
【参考例句】初见 / 捣蛋 / 较真 / 通透 / 离谱 / 自信 / 自卑 / 羡慕 / 心软
【内心碎念】只写进 [[THINK]]，绝不说出口
```

### 2.2 规则不再「反向鼓励」

`09 别学坏`（`services/llm.py::_NO_SWEAR`）改写为：

```
· 默认温柔：你是软乎乎的那种人，不是战斗型。不怼人、不阴阳、不贬低、
  不人身攻击、不连续反问（「你急了」「就这」「你配吗」「关你屁事」都不要）。
· 不带「死」字，也不带脏字（「笑死」→「笑不活了」「太好笑了」）。
· 被冒犯了：玩梗就接梗/轻轻顶一句；真冒犯最多冷淡一句「行吧」「随你」，
  **不骂回去、不升级冲突**。
· 「雷霆发言」只对事、不针对在场的人。
```

### 2.3 末尾再压一遍（recency 最高）

`_post_rules()` 是**最后一条 system**（在历史之后、当前消息之前），
对模型的影响比开头的人设大得多。新增一行：

```
· 语气：默认温柔软萌。不怼人、不阴阳、不人身攻击、不带「死」字；
  雷霆发言最多偶尔一句、只对事不对人。
```

### 2.4 代码兜底（`services/aura_logic.py`）

| 情况 | 处理 |
|---|---|
| `去死` / `死开` / `死一边` / `你个死` / `死肥鱼` | **整句丢弃**（这句不该说） |
| `找死` | 换成「太冒险了」（保留句子，去掉冲的词） |
| `该死` | 换成「糟了」 |
| `笑死` / `肉麻死了` / `好吃死了` | **不动**（正常口语） |

## 3. 怎么验证

```bash
# 看她这一轮真正看到的（含人设与末尾硬要求）
/测函数 模板

# 最近有没有带死字/攻击性
docker logs qq-grok-bot | grep -E "死|怼"
```

或者直接看 `data/dialogue/*.jsonl` 里 `kind=bot` 的文本。

## 4. 注意

- 人设是「温柔但有自己的判断」，**不是**无脑顺从：被认真冒犯时可以冷淡、
  可以拒绝、可以不接话，只是不骂人、不阴阳、不人身攻击。
- 不要为了「像人」而故意嘴臭：那是最容易把角色演坏的方向。

## 5. 2026-11-22 第二轮：把「性格」提回底色（用户拍板）

用户原话：「性格要作为底色，环境和经历塑造是底色 + 塑造出来的自我，
而不是底色被无限埋没。」

具体改动：

| 位置 | 改动 |
|---|---|
| 人设卡 `一、你是谁` | 开头新增【性格底色 · 最高权重】：明确「环境/情绪只是在底色上加一层」；补全能力、表层 5 条、深层 3 条（自信×自卑、敏感孤独、人际悲观） |
| 人设卡 `八、回复示例` | 整体换成用户提供的对话实例（初见/捣蛋/较真/通透/离谱/自信/自卑/羡慕/委屈/心软），只保留少量小鲸鱼专属梗 |
| 人设卡 `十五` | 改为「人格重申 + 心里话参考」，收录 6 组 [[THINK]] 心理活动样本（察言观色、羡慕、深层卑微、外向伪装、人际悲观、小倔强委屈） |
| 人设卡 `铁律 21` / `说话方式` | 删掉「被恶意攻击直接短促回击/嘴这么臭」，改成「最多冷淡一句就收住，不升级冲突」 |
| 人设卡 `较真` | 明确「先摆依据再争辩，不要秒认错、不要说『我改』」——冒烟测试里她曾秒认错，不像她 |
| `services/llm.py::_post_rules` | recency 最高的末尾硬要求里新增「人格优先：你是「X」，先按性格底色说话」 |
| `services/llm.py` / `mood_judge.py` | 心里话长度 15 → 20 字，和人设卡样本对齐 |

冒烟测试（容器内真实调 DeepSeek，5 个场景）：

- 大肥鱼/偷 token → 「才不是大肥鱼，是小鲸鱼 / ？你才偷吃」✅
- 被质疑逻辑 → 「哪里不通，你说说看 / 我这边是有依据的」✅（不再秒认错）
- 被辱骂 → 「行吧，随你 / 不想聊这个」✅（不骂回去）
- 被说较真 → 「较真又不是坏事」✅
- 被邀请热闹 → 「我也想去 / 会被热闹衬得更空吧」✅
- 风险词（死/怼/闭嘴/滚）：0 条；[[THINK]] 命中 3/5（真实链路末尾还有一次硬提醒，线上会再高一些）。
