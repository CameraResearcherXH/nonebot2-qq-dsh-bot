## 3. 新功能逐项

### 3.1 接话前读气氛（`services/atmosphere.py`）

- 405 轮流水线中 **181 轮**带气氛块（私聊/空 gid 不读，符合设计）。
- **16 次**真的点名到人，**14 次**判成非「日常」——说明它只在明显有情绪时才具体说，不是每轮硬编。
- 真机样例：

```text
[ATMO] 气氛=尴尬｜ヽ(｀д´)ノ：求助被敷衍，有点憋屈｜先回应他的求助，别跟着刷梗
[ATMO] 气氛=尴尬｜屑萌新喵：被质疑后有点不耐烦｜别继续抬杠，先缓一句再聊
[ATMO] 气氛=日常｜—：—｜顺着斗图接话，别冷落提问的人
```

- 成本：约 **92k token / 24h（≈1.1%）**；以前被并进 `other`，本轮已把
  `atmosphere` 加进 `llm_usage.PURPOSES`，以后单独归因。
- 延迟：与 ①②③ 并行，流水线 p95 仍 **2.5s**（见 §6）。

### 3.2 引用互刷（根因比预想的深一层）

- 16h 内「引用她」**64 次**；修复前 `引用回复她 → 交给模型自己决定` **0 次**、
  `[LOOP]` **0 次** —— 说明引用她仍被当成 @ 必回。
- **根因**：`_at_me()` 第一行 `if event.to_me: return True`，而 `to_me` 同时包含
  「@她」和「引用她」→ 永远走不到 `_quote_me()`。
- 修复后（2026-11-27 09:55 部署）：
  - 先看消息里有没有**真 `at` 段**指向她 → 必回；
  - 再判 `_quote_me()` → 软通道，交给模型 `send / stay_silent`；
  - 最后才用 `to_me` 兜底。
- 假事件验证（容器内）：

```text
quote_of_her  _quote_me: True   _at_me: False
at_her        _quote_me: False  _at_me: True
```

- 护栏：同一对 120s 内第 3 次 → 冷却 5 分钟；本轮窗口内没有出现这种 cluster，
  所以 `[LOOP]` 为 0 是正常的；下一条「引用她」的真机日志会打印
  `引用回复她 → 交给模型自己决定`，可作为线上确认。

```text
好感v1 +0.002（Δ+0.22/dv+0.090/speaker/target=speaker） → +0.18
好感v1 +0.003（Δ+0.22/dv+0.101/speaker/target=speaker） → +0.19
```


→ 锚点位移 ±0.06~0.09，事件步进 +0.004~0.025，**锚点确实是主项**；
`dv` 仍只含事件步进（好感不吃锚点，符合 ADR-042 边界）。
