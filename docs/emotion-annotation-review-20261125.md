## 0. 结论

### 0.1 设计返工：标签源错了（2026-11-25 晚，用户指出）

前两版（`emotion_annotation_200*` / `emotion_annotation_v1_1*`）的做法是
**从群聊里抽消息、看对话猜她的心情**。这是方向性错误：

- 她的心情只写在她自己的 `[[THINK|…]]` 里（`data/mood_think.json`）；
- 线上 `mood_judge` 也是读这段心理活动，不是读对话；
- 拿对话反推，既没有依据，也会把「对方回了短句」误判成「她被冷落」。

**两版旧数据全部作废，只留档，不要再用于评测。**

### 0.2 当前版本：`emotion_annotation_think_v1.jsonl`

| 项 | 值 |
|---|---|
| 标签源 | `think`（她的第一人称心理活动） |
| 输入 | `src`（她当时在回的那句）+ `reply`（她回的） |
| 规模 | **190 条**（`auto=false`，按 `(think, src)` 去重） |
| 分布 | -1×58 / 0×69 / +1×61 / +2×2（非零 **121，64%**） |
| 状态 | `ai_reviewed_think_v1`（人工抽检后改 `agreed`） |
| 校验 | `check_emotion_labels.py --strict` 通过 |

对比旧版：旧 270 条非零只有 36（13%），且标签是猜的；新版 121（64%），每条都有她自己的原话作依据。

> 下面 §1–§4 记录的是旧口径的返工过程（问题清单仍然成立：枚举越界、标签退化、
> 反讽标错、身份搞错），留作教训；**抽样与标签源以 §0.1 和规范 §1 为准**。

## 1. 发现的问题

### 1.1 复核表 md 被换行打断（渲染层）

5 行单元格里有换行（`emo_037 / 080 / 081 / 084 / 160`），表格从该行起错位。
→ v1 的 md 生成器统一转义：`\n` → ` ⏎ `、`|` → `｜`，并限长。

### 1.2 取值不合规范（硬错误）

规范 §2.1 规定 `relation_relevance` / `unexpected` 只能取 **0 / 0.5 / 1**，实际：

| 字段 | 越界值 | 条数 |
|---|---|---|
| `relation_relevance` | 0.6 | 13 |
| `unexpected` | 0.2 | 8 |

根因是预标 prompt 写的是「0.6~1.0」「日常寒暄 0.2~0.4」。
→ prompt 改成三档；`_norm_label` 加收敛；v1 全部归一。

### 1.3 标签退化（最严重）

| 字段 | 预标分布 | 问题 |
|---|---|---|
| `impact` | -1×8 / **0×184** / +1×8 | 92% 为 0，QWK 没有方差 |
| `arousal` | **low×193** | 3 档退化成 1 档 |
| `dominance` | **low×194** | 同上 |
| `unexpected` | **0×192** | 同上 |
| `confidence` | **1.0×192** | 反讽/歧义也报 1.0，校准必然失效 |

→ 归一规则（`finalize_emotion_labels.py`）：

- `arousal`：|impact| 0/1/2 → low/mid/high；
- `dominance`：impact<0 → low，其余 mid（0 值条目是「没变化」，不是「没掌控感」）；
- `relation_relevance`：other/world/self → 0；直接冲她 → 1.0；间接 → 0.5；
- `unexpected`：只有反讽/翻脸才 0.5；
- `confidence`：hard/tease/改标条目 0.6，其余 0.9（不再出现 1.0）。

### 1.4 类别与规范锚点矛盾（**已返工**）

- `ignore` 20 条预标全 0。我一开始按「锚点：被冷落一句 = -1」把其中 15 条改成 -1，
  **这是错的**：锚点说的是「她**感到**被冷落」，而「对方只回 ？/6/行吧」只是对方的行为，
  她的下一句通常照常聊。已全部回退 0（详见 §3.4）。
- `hard` 15 条全部 0 且 `is_sarcasm` 全 false —— 这一类就是反讽/歧义，一条都没标出来。
  这部分仍然成立，已补 `emo_152`。

### 1.5 反讽标记用反了

4 条直接爆粗的标成 `is_sarcasm=true`（`emo_005/034/038/058`），
真反话（`emo_152`「你这祖先当得可真行呀～」）反而是 false。
→ 前者改 false，后者改 true。

### 1.6 对象搞错（漏判 + 误判）

**骂的是别人 / 游戏 / 厂商，却给了 -1（6 条）**：`emo_034/038/044/054/099/163`
→ 改 0、`target=other`、`relation_relevance=0`。

**明显冲她说的，却给了 0（7 条）**：`emo_013`（叫她滚）、`emo_064/070/119`（当面夸她/贴贴）、
`emo_128`（越界玩笑）、`emo_158`（叫她闭嘴）、`emo_186`（夸她呆毛）→ 按锚点改 ±1。

> `emo_071`（拒绝贴贴）和 `emo_177`（叫傻鱼）一度也被改成 -1，后按 §0.1 的口径回退 0：
> 前者语气平和、她回「一声招呼也够用了」；后者她顺着玩笑接「这叫有格调的鱼」。

### 1.7 其他

- `target=self` 用在 3 条群友自述上（`emo_100/104/123`）→ 改 `speaker`。
- `reason` **148 条为空** → 按 impact/target 填事件描述。

### 1.8 身份搞错：`大肥鱼(9194)` 就是她

这是本轮最重要的发现。语料里有两个「大肥鱼」：

| 显示名 | 实际身份 |
|---|---|
| `大肥鱼(9194)` | **她本人**（新号 100000010），引用内容能和她的 bot 发言逐字对上 |
| `这是一只大肥鱼🐟(5193)` | 群友 |

`build_emotion_annotation.py` 的 `bot_alias` 没把「大肥鱼」算成她，
导致预标把大量「冲她说」的消息当成第三方闲聊。v1 已修 2 条（177/186），
重抽脚本把「名字 + QQ 后四位」双匹配写死了，避免再撞车。

## 3. v1.1：按「冲她说」重抽 70 条

### 3.1 为什么重抽

v1 的 200 条按**关键词**抽（夸/骂/关心…），大量条目在夸别人、骂别人，
impact 0 仍占 83%。要测「判读准不准」，样本必须**冲她**。

### 3.2 怎么抽（`scripts/sample_addressed_emotion.py`）

只保留三种硬信号：

| 信号 | 判定 |
|---|---|
| `at` | `@100000010` / `@100000018` / `@小鲸鱼` / `@大肥鱼`（带 QQ 时以 QQ 为准） |
| `quote` | `〔引用 她的名字(QQ后四位)…〕`，名字与后缀必须**同时**命中 |
| `name` | 正文出现她的名字（已剥掉引用块、排除 `这是一只大肥鱼🐟`） |

排除：机器人自己的话、纯图/表情/链接、哈希答案、`len<3`、文本重复、已在 v1 的文本。
选样：带情绪词的（负/正/道歉）**全收**，再用中性补足；群 ≤60%、单人 ≤15 条。

### 3.3 结果

| | 数量 |
|---|---|
| 17 天语料 | 40,610 条 |
| 冲她说候选 | 439 条 |
| 抽中 | **70 条**（at 31 / quote 19 / name 16 / quote+name 4） |
| 覆盖 | 11 天 / 9 个群 |

逐条复核（按 §0.1 口径返工后）：**-1×6 / 0×51 / +1×13**。

合并后 v1.1：

| | -2 | -1 | 0 | +1 | +2 |
|---|---|---|---|---|---|
| v1（200） | 0 | 5 | 183 | 12 | 0 |
| 冲她说（70） | 0 | 6 | 51 | 13 | 0 |
| **v1.1（270）** | 0 | **11** | 234 | **25** | 0 |

非零样本 17 → **36（13%）**，criticism 类 -1 从 4 → 10。

### 3.4 口径返工：impact 不能从对方行为反推

用户抽查时发现：`ignore` 那 15 条 -1 全是「对方回了个短句 → 判她被冷落」，
标的是**对方的行为**，不是**她的心理状态**。核对她的后续发言后确认：

- 15 条里她的下一句都在正常接话（「干嘛」「炸鱼就是爽」「来点有难度的」…），没有不悦；
- 同理回退的还有 `emo_071`（她回「一声招呼也够用了」）、`emo_177`（她回「这叫有格调的鱼」）；
- 新增 70 条里 6 条轻度外号（傻鱼/大傻鱼/蠢猪）也回退 0：她要么顺着玩笑接，要么根本没反应。

合计 **23 条 -1 → 0**。判据写进 `docs/emotion-labeling-guide.md` §0.1：
**先看她自己的下一句；没有反应就看是否明确针对她的评价行为；两者都没有就是 0。**

```bash
python3 scripts/sample_addressed_emotion.py --dir <对话目录> --limit 70 --write
python3 scripts/merge_emotion_additions.py --write
python3 scripts/check_emotion_labels.py data/eval/emotion_annotation_v1_1.jsonl --strict
```

> 重抽需要 `data/dialogue/*.jsonl` 全量语料（本地只有 1 天测试数据，本次是从服务器只读同步到 `/tmp/dlg_srv` 跑的）。

## 4. 仍然存在的风险

1. **方差很低**：按修正后的口径，v1.1 非零只有 36/270（13%），且**没有 -2 / +2**。
   这不是抽样漏了，是她真的很少被这些话影响：短句接话、外号调侃，她基本都照常聊。
   要让 QWK 有意义，下一版应按「**她自己的反应**」抽样（她炸毛/委屈/害羞/道谢的那些轮），
   再回头标触发它的那条消息，而不是按关键词或收件人抽。
2. **ECE 还测不了**：`eval_emotion_labels.py` 单人模式对照的是 `auto_suggest` 规则基线，
   不是人工真值；本次已把 ECE 从单人模式输出里摘掉。
3. **双人 QWK 仍要人工做**（规范 §3 前 50 条重叠集），41 + 70 条改标目前是单模型复核。
4. 重抽只覆盖 11 天 / 9 个群，不能当全体分布用。
