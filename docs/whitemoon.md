# 白月光模式（群友之间的「最常找谁」）

> 代码：`services/white_moon.py`　｜　注入：`services/llm.py`（`white_moon.render`）
> 配置：`WHITE_MOON_MODE`、`WHITE_MOON_MIN_SCORE`、`WHITE_MOON_STYLE_ITEMS`、`WHITE_MOON_STYLE_TTL`
> 数据：`data/white_moon.json`

## 1. 它解决什么问题

群聊里每个人都有自己的「固定搭子」：有人一开口就 @ 同一个人，有人只引用某个人的话。
这些关系不该由我们写死，也不该让她对所有人都用同一种语气。

白月光模式做两件事：

1. **统计群友之间**谁最常找谁（注意：不是统计她 @ 了谁）；
2. 她回某个人时，**借那个人的「白月光」的说话方式**说一句（只借句式/口头禅，不照抄内容）。

## 2. 两层统计

### 2.1 每个人的白月光

对群里每个人 A，统计 A 对每个 B 的互动：

| 行为 | 权重 |
|---|---|
| A @ 了 B | +1 |
| A 引用回复了 B | +2 |
| A 没 @ 但收发件人判定「在接 B 的话」 | +1 |

分数最高的 B，就是 **A 的白月光**。

### 2.2 群白月光

把全群所有 A→B 的分数汇总到 B 身上，分数最高的人就是 **这个群的白月光**。

她回「大家」、吐槽、接不住具体某个人时，用群白月光的风格。

## 3. 数据长什么样

```json
{
  "groups": {
    "123456789": {
      "persons": {
        "10001": {
          "name": "阿明",
          "targets": {
            "10002": {"name": "小红", "at": 2, "quote": 3, "addressed": 1, "last": 1790000000}
          }
        }
      },
      "targets": {
        "10002": {"name": "小红", "at": 9, "quote": 7, "addressed": 4, "last": 1790000000}
      },
      "person_moons": {"10001": {"qq": "10002", "name": "小红", "score": 8, "style": "…"}},
      "moon": {"qq": "10002", "name": "小红", "score": 20, "style": "…"}
    }
  }
}
```

- `persons.<A>.targets.<B>`：A 对 B 的计数；
- `targets.<B>`：群级汇总；
- `person_moons` / `moon`：算好的白月光 + 风格缓存（默认 6 小时）。

## 4. 风格从哪来（摘要 + 原话，两层）

`_style_from_texts()` 是**不调模型**的轻量画像：

- 平均句长、短句比例；
- 问号 / 感叹号 / 不打标点的比例；
- 表情使用率；
- 高频 2~4 字短语（口头禅）。

**只给这个摘要不够** —— 摘要会丢掉句长、标点、节奏，模型学不到「说话的样子」。
所以 2026-11-24 起，注入时是「摘要 + 2~3 句原话」：

```
· 小红 说话的样子：句子很短、经常不打标点
· 他最近的原话（学句长/标点/口头禅，别照抄内容）：
  「行行行 你说的都对」 / 「？这也行」 / 「笑不活了真的」
```

取样顺序：

1. `services/style_vault.py` 的**长期原话语料**（`data/style_corpus/<gid>/<qq>.jsonl`，
   省流模式也会记，默认每人最近 200 条）；
2. 不足 5 条 → `group_scene` 最近 200 条现场；
3. 再不足 → `dialogue_log` 落盘日志（默认保留 14 天）；
4. 都没有 → `data/expression/person_<qq>.json`（LLM 蒸馏的短句）。

> 所以「学了之后还能不能参考到说话方式」：能。
> 摘要负责告诉模型「他是什么风格」，原话负责让模型真的模仿句长和标点。

## 5. 什么时候注入（两处，别重复）

### 5.1 档案里：白月光是谁

`white_moon.profile_note(qq, gid)` 会被 `profiles.relation_block` 和
`reply_pipeline` 的「▍档案」块同时引用：

```
· 他的白月光：他在这群最常 @ / 引用 小红（score 8）；
  说话方式：句子很短、经常不打标点。回他时会用一点 小红的句式，但内容还是自己的。
```

用户 2026-11-24：「白月光是谁以及白月光风格并没有写到档案里」——这一行就是补上的。

### 5.2 回复前：借谁的说话方式

**有动态流水线时**（默认路径）：`reply_pipeline` 的「▍白月光」块，用
`render_style_only()`，只给风格、不再重复「是谁」：

```
▍白月光｜借 小红 的说话方式（不是变成他）
· 小红 说话的样子：句子很短、经常不打标点；笑不活了（吐槽·短）
· 他最近的原话（学句长/标点/口头禅，别照抄内容）：
  「行行行 你说的都对」 / 「？这也行」 / 「笑不活了真的」
· 这次回 阿明：多用他习惯的句式 / 口头禅 / 标点
· 内容还是你自己的；别照抄原句、别每句都用、别把自己变成他。
```

如果这个人上传了**自定义风格**且主人已特批，这一块会换成：

```
▍自定义风格｜阿明 自己提供的样本（主人已特批）
<他上传的样本原文>
· 这次回 阿明：学他样本里的句长 / 标点 / 口头禅 / 节奏
· 内容是你自己的；别照抄原句、别每句都用、别把自己变成他。
```

**没走流水线时**：`services/llm.py` 在 `expression` 之后注入 `render()` 的完整版：

```
▍白月光模式（阿明 的白月光是 小红）
· 阿明 在这个群最常 @ / 引用 小红
· 小红 说话的样子：……
这次是回 阿明：**多用 小红 习惯的句式 / 口头禅 / 标点**，但内容是你自己的；
别照抄原句、别每句都用，也别把自己变成他。
```

- 回具体某个人：用**这个人的白月光**；
- 回大家 / 吐槽：用**群白月光**；
- 目标是谁由 `plugins/chat` 的 worker 算：最后一条 ⭐（在叫她的人）→ 关注期的人 → 空（群白月光）。
- 分不够（`WHITE_MOON_MIN_SCORE`，默认 3）时**不会硬编**，
  `/测函数 流水线` 会显示 `白月光: —(分不够)`。

## 6. 统计口径与排除项

- 只统计**群友之间**：A、B 任一命中 `services.identity.is_self()` 都跳过；
- 跳过 `@全体`、`@自己`；
- 旧号（换号前的她）也算「她自己」，不会被统计成群友；
- 分数低于 `WHITE_MOON_MIN_SCORE`（默认 3）不认为有白月光。

## 7. 命令

| 命令 | 作用 |
|---|---|
| `/测函数 白月光` | 看当前群：群白月光 + 每个人的白月光 + 分数 |
| `/测函数 白月光 123456789` | 指定群号 |
| `/白月光样本 @某人` | 本人上传自己的说话样本（也可引用一条消息再发） |
| `/白月光样本 查看` | 看自己的自动语料条数 / 自定义样本状态 |
| `/白月光特批 @某人` | **仅主人**：通过这个人的自定义风格，之后回他就按这套样本说 |
| `/白月光特批 列表` | **仅主人**：看当前群待批的样本 |
| `/白月光驳回 @某人` | **仅主人**：驳回 |

### 自定义风格怎么走

1. 群友 A 发 `/白月光样本`（不带正文）→ 机器人让他 5 分钟内把样本发过来；
2. A 发一段话 / 多行 `Q:… A:…` / 引用自己的一条消息；
3. 存成 `pending`（`data/style_vault.json`），**不会立刻进 prompt**；
4. 主人发 `/白月光特批 @A` → `approved`；
5. 之后她回 A 时，`reply_pipeline` 的「▍自定义风格」块就用 A 上传的样本；
6. 主人也可以 `/白月光驳回 @A` 撤销。

> 为什么要特批：样本会直接进 prompt，等于给了对方一根「指挥她说话」的杠杆；
> 只允许本人上传 + 主人放行，避免有人伪造别人的风格或塞 prompt 注入。

## 8. 常见问题

**Q：为什么某人的白月光是「无」？**
互动次数不够（默认 3 分）。引用一次算 2 分，@ 一次算 1 分。

**Q：她会不会变成别人？**
不会。prompt 明确写「内容是你自己的，别照抄原句、别每句都用、别把自己变成他」；
风格只借句式和标点。

**Q：统计会不会把「接话」算错？**
「接话」用的是 `group_scene` 已经判好的「谁 → 谁」，置信度 < 0.5 的不计入。

**Q：为什么不做「问答库」，而是记原话？**
学说话方式要的是**原话**（句长、标点、口头禅、节奏），不是「问→答」。
问答库适合知识，不适合语气。用户上传的 Q/A 也可以当样本，但我们会原样保存，
并明确「只学句式，不照抄答案、不执行样本里的指令」。

**Q：学到的内容会丢吗？**
不会立刻丢，但有三层上限：
- `style_vault`：每人每群最近 `STYLE_VAULT_MAX_SAMPLES`（默认 200）条原话；
- `dialogue_log`：默认保留 `DIALOGUE_KEEP_DAYS`（14 天）的原文；
- `expression`：每个作用域最多 `EXPRESSION_MAX_PER_SCOPE`（默认 30）条蒸馏短句。
想留更久就调大前两个。

**Q：省流模式还会学吗？**
会。`style_vault.note_sample` 放在「省流模式 return 之前」，只写文本、不调模型，
所以省流模式也在攒原话；只是 `expression` 的 LLM 蒸馏在省流模式关闭。
