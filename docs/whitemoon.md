# 白月光模式（群友之间的「最常找谁」）

> 代码：`services/white_moon.py`　｜　注入：`services/llm.py`（`white_moon.render`）
> 配置：`WHITE_MOON_MODE`、`WHITE_MOON_MIN_SCORE`、`WHITE_MOON_STYLE_ITEMS`、`WHITE_MOON_STYLE_TTL`
> 数据：`data/white_moon.json`

## 1. 它解决什么问题

群聊里每个人都有自己的「固定搭子」：有人一开口就 @ 同一个人，有人只引用某个人的话。
这些关系不该由我们写死，也不该让她对所有人都用同一种语气。

白月光模式做两件事：

1. **统计群友之间**谁最常找谁（注意：不是统计她 @ 了谁）；
2. 她回某个人时，**借那个人的「白月光」的说话方式**说一句（只借句式/口头禅，不照抄内容）。

## 2. 两层统计

### 2.1 每个人的白月光

对群里每个人 A，统计 A 对每个 B 的互动：

| 行为 | 权重 |
|---|---|
| A @ 了 B | +1 |
| A 引用回复了 B | +2 |
| A 没 @ 但收发件人判定「在接 B 的话」 | +1 |

分数最高的 B，就是 **A 的白月光**。

### 2.2 群白月光

把全群所有 A→B 的分数汇总到 B 身上，分数最高的人就是 **这个群的白月光**。

她回「大家」、吐槽、接不住具体某个人时，用群白月光的风格。

## 3. 数据长什么样

```json
{
  "groups": {
    "123456789": {
      "persons": {
        "10001": {
          "name": "阿明",
          "targets": {
            "10002": {"name": "小红", "at": 2, "quote": 3, "addressed": 1, "last": 1790000000}
          }
        }
      },
      "targets": {
        "10002": {"name": "小红", "at": 9, "quote": 7, "addressed": 4, "last": 1790000000}
      },
      "person_moons": {"10001": {"qq": "10002", "name": "小红", "score": 8, "style": "…"}},
      "moon": {"qq": "10002", "name": "小红", "score": 20, "style": "…"}
    }
  }
}
```

- `persons.<A>.targets.<B>`：A 对 B 的计数；
- `targets.<B>`：群级汇总；
- `person_moons` / `moon`：算好的白月光 + 风格缓存（默认 6 小时）。

## 4. 风格从哪来

`_style_from_texts()` 是**不调模型**的轻量画像：

- 平均句长、短句比例；
- 问号 / 感叹号 / 不打标点的比例；
- 表情使用率；
- 高频 2~4 字短语（口头禅）。

取样优先 `data/expression/person_<qq>.json`（她平时学到的这个人说话方式），
不足 5 条就退回落盘日志里这个人最近说的话。

## 5. 什么时候注入

在 `services/llm.py` 的主聊天 prompt 里，`expression` 之后注入一段：

```
▍白月光模式（阿明 的白月光是 小红）
· 阿明 在这个群最常 @ / 引用 小红
· 小红 说话的样子：句子很短、经常不打标点；笑不活了（吐槽·短）
这次是回 阿明：**多用 小红 习惯的句式 / 口头禅 / 标点**，但内容是你自己的；
别照抄原句、别每句都用，也别把自己变成他。
```

- 回具体某个人：用**这个人的白月光**；
- 回大家 / 吐槽：用**群白月光**；
- 目标是谁由 `plugins/chat` 的 worker 算：最后一条 ⭐（在叫她的人）→ 关注期的人 → 空（群白月光）。

## 6. 统计口径与排除项

- 只统计**群友之间**：A、B 任一命中 `services.identity.is_self()` 都跳过；
- 跳过 `@全体`、`@自己`；
- 旧号（换号前的她）也算「她自己」，不会被统计成群友；
- 分数低于 `WHITE_MOON_MIN_SCORE`（默认 3）不认为有白月光。

## 7. 命令

| 命令 | 作用 |
|---|---|
| `/测函数 白月光` | 看当前群：群白月光 + 每个人的白月光 + 分数 |
| `/测函数 白月光 123456789` | 指定群号 |

## 8. 常见问题

**Q：为什么某人的白月光是「无」？**
互动次数不够（默认 3 分）。引用一次算 2 分，@ 一次算 1 分。

**Q：她会不会变成别人？**
不会。prompt 明确写「内容是你自己的，别照抄原句、别每句都用、别把自己变成他」；
风格只借句式和标点。

**Q：统计会不会把「接话」算错？**
「接话」用的是 `group_scene` 已经判好的「谁 → 谁」，置信度 < 0.5 的不计入。
